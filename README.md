# Book-Management-API
Book-Management-API merupakan sebuah API yang digunakan untuk memanajemen buku sesuai dengan kategorinya. Selain itu Book-Management-API ini juga ditujukan sebagai tugas QUIZ pada course sanbercode.com tentang pada periode kelas backend-golang-batch-79.
<br>
## 🛠️ Tech Stack
Berikut merupakan tech stack yang digunakan pada project ini.
- **Language:** Go (Golang)
- **Framework:** Gin Web Framework
- **Database ORM:** GORM
- **Database:** PostgreSQL
